# koolskools-website

A fully coded design prototype of the new Koolskools website and shop.

## How to run the code

Install `git` and `Node.js` if they are not already installed:

- git: https://git-scm.com/install/
- node: https://nodejs.org/en/download

Then use your computer's terminal and run the following commands:

```shell
# Download the code base
git clone https://github.com/tamrachan/koolskools-website

# Make sure you're in the right directory
cd koolskools-website/KoolSkools-website

# Install the dependencies
npm install

# Run the website in developer mode
npm run dev
```

You should see something like:

```shell
npm notice run koolskools-website@0.0.0 dev
npm notice run vite

  VITE v8.0.16  ready in 142 ms

  ➜  Local:   http://localhost:5173/
  ➜  Network: use --host to expose
  ➜  press h + enter to show help
```

You can then go to http://localhost:5173/ in your browser to see the website.
